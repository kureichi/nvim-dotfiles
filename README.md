I've tried to keep it as clean as possible, but it still has the essential features I need.

## What's in here:
* LSP handled by mason.nvim, from server installation to automatic launch
* Automatic installation of the treesitter parser when opening a file
* Improved error lens with tiny-inline-diagnostic.nvim
* File navigation with oil.nvim for better focus (I used neo-tree, but I'm trying to switch to oil because I need to focus on open buffers only)
* Window navigation with CTRL + h/j/k/l in normal mode
* Open terminal with SPC + tf (floating) or SPC + th (horizontal)
* Open lazygit directly with toggleterm (floating), the shortcut is SPC + gg, close it without closing the lazygit instance with CTRL + / in terminal mode
* UI with noice.nvim
